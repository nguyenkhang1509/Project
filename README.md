# AuraK Levelling

AuraK Levelling is a gamified personal growth web application built to turn self-improvement into a structured progression system. It helps users track personal development across key life pillars, complete quests, earn XP, maintain streaks, and reflect through a modern dashboard experience.

## Overview

The platform combines a polished front-end interface with account-based progress tracking. New users move through an onboarding flow that introduces the system, gathers survey input, and generates their starting stats. From there, users can access their dashboard, profile, journal, quests, and analytics pages to monitor progress over time.

AuraK is designed around five core pillars:

- Physical
- Intellectual
- Mental
- Confidence
- Discipline

## Features

### Authentication and onboarding
- User registration and login flow
- Guided entry experience from intro page to dashboard
- Survey-based baseline stat generation
- Loading and sequence screens for a smoother onboarding experience

### Dashboard
- XP and level progression system
- Core stat display across five pillars
- Progress overview and growth-focused UI
- Activity and completion tracking

### Profile system
- Customizable user profile page
- Dynamic profile presentation
- Personal information and rank display
- Title and identity-based profile elements

### Quests
- Quest-based progression structure
- Reward and completion tracking
- Growth-oriented challenge system tied to user improvement

### Journal
- Reflection and self-tracking page
- Space for daily or ongoing progress logs
- Supports habit-building and consistency

### Analytics and stats
- Stats page for user growth overview
- Rank and progression visualization
- Structured feedback on improvement areas

### UI and design
- Minimal, polished, futuristic interface
- Multi-page front-end architecture
- Responsive and organized layout design
- Theme support through dedicated styling and theme logic

## How It Works

1. Users start from the intro and onboarding pages.
2. They register or log into their account.
3. The survey helps establish their initial stats and growth profile.
4. The app routes them into the dashboard and connected pages.
5. Users continue improving through quests, journaling, tracking, and profile progression.

## Getting Started

1. Clone or download this repository.
2. Extract the project files.
3. Open `intro.html` in a modern web browser.

For the best experience, run the project through a local server if needed for JavaScript modules and Firebase integration.

## Firebase Integration

This project includes Firebase-related files for authentication and user data handling.

- `firebase.js` handles Firebase setup
- `userStore.js` manages user-related data logic

To use your own Firebase project:

1. Create a Firebase project
2. Enable the required services
3. Replace the configuration values in `firebase.js`
